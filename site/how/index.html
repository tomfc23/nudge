How it reaches you

Four hops, all of them yours.

  1. 01

    Your agent

    OpenCode reports turn boundaries, permission asks, form prompts, and tool failures.

  2. 02

    Nudge

    The plugin classifies the event, formats a lock-screen caption, and publishes one JSON request.

  3. 03

    Your ntfy server

    The server runs on infrastructure you control. Auth is enabled by default: anonymous users may subscribe, only your token may publish.

  4. 04

    Your phone

    Subscribe to one topic in the official ntfy app. On iOS, the server forwards a content-free wake signal so pushes arrive while the app is closed.
