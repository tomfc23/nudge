Install path

Hand it to your agent. Answer five questions.

The installer provisions the ntfy server, wires the plugin, and sends a test push you confirm on your phone. Nothing runs until you have answered.

Run this in a terminal on the machine where your agent runs:

curl -fsSL https://nudge.tommyek.com/install.sh -o install.sh && NTFY_SITE_URL=https://nudge.tommyek.com sh install.sh

Needs Docker (or Colima) and Node. The installer offers to install missing tools with your consent.
